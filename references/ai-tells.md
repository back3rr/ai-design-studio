# AI-tells checklist

Patterns that make a design read as "generated by default". Not every item is always wrong — a gradient can be a deliberate choice — but each one found needs a reason to stay. If there's no reason, fix it.

Run the **visual + interaction** pass and the **copy** pass separately, and report each one's changes separately.

## Visual

- Purple/blue/teal gradients, especially behind the hero
- Soft glowing blobs or orbs in the background; faint grid or dot-pattern backgrounds
- Hero formula: headline + subhead + button on the left, graphic or card on the right
- A row of three identical feature cards, each with an icon in a tinted circle
- Glassmorphism panels; the same large corner radius and soft shadow on everything
- Default type stack with no considered pairing; every section center-aligned
- Perfectly uniform spacing everywhere — no rhythm, no tension
- Emoji used as icons; sparkle "New" badges in the hero
- Highlight colors or colored text with no meaning attached
- Decoration made of CSS shapes where an image or nothing would be better
- Custom buttons/inputs that look worse than native platform components
- Too many font sizes/weights; no clear typographic hierarchy
- Stock "logo cloud" or "trusted by" strip with invented logos

## Interaction / motion

- Every hover is scale-up + bigger shadow
- Every section fades/slides in on scroll
- Animations with no purpose (they don't show a state change or guide attention)

## Copy

- Inflated headlines: "Supercharge…", "Unlock the power of…", "Elevate your…", "Seamlessly…"
- "It's not just X, it's Y" and other contrast-for-effect constructions
- Throat-clearing openers and filler ("In today's fast-paced world…")
- Grand verbs that pretend depth: empower, revolutionize, transform, unleash, harness
- Groups of three adjectives or three parallel clauses as a reflex
- Every sentence the same length and rhythm
- Heavy use of long dashes as a stylistic tic
- Invented numbers, testimonials, or customer logos — remove these entirely or mark them as placeholders for the user to replace with real ones
- Text that explains what the UI already makes obvious

## Report format

For each tell found:

```
[Visual|Interaction|Copy] — where (section/element) — what it is — smallest fix
```

Then apply the fixes and show before/after screenshots for the visual pass and a before/after text diff (plain language, not code) for the copy pass.
